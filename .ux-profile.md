# UX Profile

Dibuat oleh `setup-ui-ux-skills`. Semua skill UI/UX di proyek ini membaca berkas ini sebelum mengubah tata letak, teks, atau interaksi.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** Ikuti `design/DESIGN.md` dan token di `design/tokens.css`: palet daun/kertas/vanili (60-30-10, vanili satu-satunya aksen), Raleway di landing, font sistem di dashboard, radius 14 px (panel) dan 10 px (kontrol), tanpa bayangan (pemisah memakai `--line`). Tema terang sebagai bawaan.

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter` tanpa batas kontras tinggi
- Badge pil pastel melayang untuk metadata biasa
- Gradien dekoratif sembarangan dan border neon bercahaya
- Gradien pelangi radial di tombol CTA
- Ilustrasi kartun di keadaan kosong (orang melambai / tos)
- Scrollbar bersarang dan ikon berlebih di dalam input

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** teks normal ≥ 4,5:1, teks besar dan garis grafik ≥ 3:1. Nilai terukur ada di `design/DESIGN.md`; `--accent` (vanili) tidak untuk teks kecil.
- **Touch / focus:** target sentuh ≥ 44×44 px, cincin fokus terlihat di setiap kontrol.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case untuk teks UI dan tombol
- **Notes:** Bahasa Indonesia sederhana untuk pengunjung pameran dan operator kebun. Tombol diawali kata kerja ("Nyalakan pompa"). Pesan galat menjelaskan apa yang terjadi dan cara memperbaikinya, tanpa menyalahkan pengguna.

## Icon library

- **Library:** Project SVG
- **Package / path:** belum ada folder; simpan di `landing/public/icons/` saat ikon pertama dibutuhkan
- **Notes:** Gambar ikon sesuai isi (pompa, tetes air, sensor tanah), garis seragam di 16–24 px. Jangan memakai emoji sebagai ikon.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
